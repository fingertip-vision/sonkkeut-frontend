# develop_ux · 3단계: 스크롤 없는 주문 확인 배치

기준 커밋: 60f6a2d. 이번 변경은 미커밋·미배포 상태다.

## 적용

- 정상 주문을 해석한 뒤 주문 확인 패널을 별도 표시한다. 남은 세로 공간은 카메라 15%, 주문 확인 85%로 배분한다. 카메라 추론 해상도·모델은 변경하지 않는다.
- 주문 확인 중 카메라 위의 반복 안내 문구와 주문 요약의 중복 표시를 제거한다. 현재 안내/오류 메시지는 상단에 유지한다.
- 주문 확인 패널에는 스크롤을 추가하지 않는다. 선택한 글자 크기를 유지하고, 긴 주문은 실제 글자 배치 높이를 측정해 이전·다음 버튼으로 나눠 읽는다. 수량 진행 내용도 같은 패널에서 확인한다.
- 직접 입력·녹음·분석 중에는 확인 패널을 숨겨 기존 입력 화면과 겹치지 않게 한다. 오류/후보 선택 및 상세 OCR의 기존 스크롤 화면은 이번 변경 범위에서 유지한다.

## 검사

- 디버그 Kotlin 앱·Android 검사 APK 빌드 성공.
- Android 15 에뮬레이터 배치 검사 2개 통과: 360×640dp, 글자 배율 1.0 및 2.6, 12개 항목의 긴 주문.
- 주문 전체 문자열의 누락 여부, 페이지 글자 잘림 여부, 스크롤 미사용, 이전·다음 접근, 축소 카메라 영역 확보를 확인했다.
- 초기 큰 글자 검사에서 한 줄 높이 부족과 페이지 경계의 빈 줄 잘림을 발견했고, 고정 진행 문구를 페이지 내용에 포함하고 실제 표시 높이로 페이지를 나눠 수정했다.
- 초기 앱 검사에서 권한 부여보다 Activity 실행이 먼저 이뤄져 카메라 프레임 대기가 시간 초과했다. 테스트 Rule 순서를 권한 부여 → Activity 실행으로 명시한 뒤 NativeAppTest 7개 모두 통과했다.
- 최종 단위 테스트 74개 통과. 마지막 소스에서 배치 검사 2개 재실행·통과. 큰 글자 배치 캡처도 확인했다.
- 손끝 안내 중 기존 시각 힌트를 유지하고, 오류 상태에서는 현재 안내 메시지를 상단에 표시한다.

이 검사는 제한된 세로 화면 조건을 대상으로 한다. 더 작은 화면·가로 화면·실물 TalkBack 사용성은 별도 확인해야 한다. 설정/종료/재인식 버튼 재구성과 복귀 정책은 4단계에서 진행한다.
