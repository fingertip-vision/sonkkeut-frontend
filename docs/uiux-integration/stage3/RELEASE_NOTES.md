# 손끝길 0.3.0 · Signal UI/UX 통합

0.2.4에서 업데이트할 수 있는 개발용 APK입니다. 실기기 검증 범위는 아래 내용을 확인해 주세요.

시작부터 주문·촬영·손끝 안내·설정까지 Signal 디자인으로 연결했습니다. 손끝 미검출, 화면 탐색, 이동, 누르기와 결과 확인을 구분하고, 실제 인식 결과가 없는 방향을 표시하지 않습니다.

큰 글씨와 밝은/어두운 테마, 설정 선택·스위치 탐색을 보완했습니다. AI 준비 재시도, 카메라 재연결, 마이크 권한 거절 시 직접 입력을 제공하며 다른 앱에서 돌아오면 직접 카메라를 다시 시작합니다. 정상 주문의 확인 팝업과 자동 안내는 유지합니다.

## 설치 파일

- `sonkkeut-0.3.0.apk`: Android 8.0 이상 ARM64, 약 70MB.
- 패키지 `com.sonkkeut`, 버전 `0.3.0`, versionCode `15`.
- 0.2.4와 동일한 개발용 서명. 기존 앱을 삭제하지 않고 APK를 열어 업데이트합니다. 독립 에뮬레이터에서 설정·권한을 보존하는 업데이트 설치와 촬영·입력·복귀 흐름을 확인했습니다. 실제 휴대폰의 기존 음성 모델 보존은 추가 확인이 필요합니다.
- 자체 Whisper 음성 모델은 APK에 포함하지 않습니다. 처음 사용하는 기기는 약 485MB 추가 다운로드가 필요하며 모델 없이 직접 주문을 입력할 수 있습니다.
- SHA-256: `1d70382dad23f22592dce671b5ec3e2beb6b2a4af51129849e4216fd6f14883c`.

## 검증 범위

단위 검사 106개, Android 15 계측 25개와 실제 설정·복귀 터치 검사를 통과했습니다. 실제 한국어 마이크 인식, 실물 키오스크 전체 주문, TalkBack 사용자 검증·물리 진동·카메라 좌표 정합성은 추가 확인이 필요합니다. 결제는 키오스크에서 직접 진행합니다.

릴리스는 포크 `develop_ui_update`의 최종 검증 커밋을 정확히 지정해 생성합니다. 원본 동기화 PR 대상은 새 `develop_ui/ux_v2`만 사용합니다.
