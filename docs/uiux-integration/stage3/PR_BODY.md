## 변경 내용

0.2.4의 Kotlin Android 앱에 손끝길 Signal 디자인을 통합하고 버전을 0.3.0 / versionCode 15로 올립니다. 시작·CameraX·주문·음성·손끝 안내·설정·복구 화면을 같은 색상과 글꼴, 큰 글씨 배치로 연결합니다.

손끝 미검출·탐색·이동·누르기·결과 확인·오류를 구분합니다. 유효한 최신 AI 이벤트가 없는 경우 방향·대상 표시를 숨깁니다. 주문 해석, 정상 주문 뒤 음성 안내와 자동 진행, 자체 Whisper, 기존 CameraX 분석과 AI 가중치는 유지합니다.

설정의 선택·스위치 semantics, 큰 글씨 스크롤, 주문 팝업 탐색 순서와 상태 안내를 보완합니다. AI 초기화 재시도·카메라 복구·마이크 권한 거절 시 직접 입력을 연결하고, 빠른 Activity 재실행 시 이전 모델의 지연된 엔진 해제가 새 모델에 영향을 주지 않도록 수명을 직렬화합니다.

## 검증

- 단위 검사 106개, Android 15 계측 25개 통과(실패·생략 0).
- 실제 터치로 설정 왕복·백그라운드 복귀·수동 카메라 재시작·종료 흐름 통과.
- debug/release 강제 재빌드와 release 필수 lint 통과. 0.3.0은 기존 `com.sonkkeut` 패키지·개발용 서명을 유지합니다.
- 독립 에뮬레이터에서 0.2.4 → 0.3.0 업데이트 설치 성공. 저장한 밝은 테마·더 큰 글씨, 권한·최초 설치 시각을 유지하고 release APK 자체의 촬영·입력·복귀·재시작 흐름을 통과했습니다.
- 상세 APK 해시·설치 검증·실제 화면/고정 상태 캡처는 `docs/uiux-integration/stage3/README.md`에 기록했습니다.

실물 키오스크/손끝 인식, 실제 마이크의 한국어 Whisper 품질, TalkBack 발화·접근성 포커스와 물리 진동은 실기기 검증이 필요합니다. 가상 카메라·텍스트 입력·Compose 고정 상태 검사를 이 검증으로 대신하지 않습니다.
