## 반영된 사용자 흐름

1. 시작 화면에는 설정과 시작 버튼을 제공하며 종료 버튼은 없다.
2. 기기 인식 대신 자체 Whisper를 사용한다. 자체 모델이 없으면 다운로드 안내와 직접 입력을 제공한다.
3. 정상 주문은 인식 원문/보정 문장/안내 시작 버튼 없이 주문 확인 내용을 표시하고 바로 안내한다. 후보 선택 또는 주문 오류가 있으면 안내를 시작하지 않는다.
4. 주문 확인에는 스크롤을 사용하지 않는다. 카메라를 축소하고 긴 주문은 글자 크기를 유지한 채 이전·다음 페이지로 표시한다. 큰 글자는 카메라/상태 영역을 더 줄인다.
5. 메인에는 설정 → 노란색 종료 버튼을 제공한다. 환경 설정에는 화면·카메라·음성 항목만 제공한다.
6. 안내 계속/중지 대신 기능 미연결 음성 재인식 비활성 버튼을 제공한다. 재안내는 유지한다.
7. 안내 중 설정에서 돌아오면 이전 목표를 폐기하고 새 화면으로 안내를 재개한다. 백그라운드 복귀는 중지 상태를 유지하며 카메라 다시 시작을 제공한다.

## 한계

실제 한국어 마이크 Whisper 추론, 실물 키오스크 전체 주문 성공률, 초광각 하드웨어, TalkBack·시각장애인 사용성은 미검증이다. 음성 인식 후 흐름 검사는 인식 텍스트를 제공해 확인했으며 실제 음성 인식 성공으로 해석하면 안 된다. 자체 Whisper는 첫 사용 시 약 485MB 모델 다운로드가 필요하다.

음성 재인식은 기능 없이 비활성 버튼만 제공한다. 서버/매장·화면 읽기·상세 OCR 등의 사용자 진입점은 환경 설정에서 제거했지만 연결/추론 코드는 유지한다. 설정의 서버 주소 변경 화면은 현재 UX에 없다. 세부 디자인은 추후 UX 담당자 디자인을 받아 적용한다.
