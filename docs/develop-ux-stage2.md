# develop_ux · 2단계: 자체 음성 및 주문 자동 안내

기준: 7c3f583 / 작업 브랜치 develop_ux. 기존 공개 0.2.1 APK와 구별되는 미배포 작업이다.

## 변경

- 루트 Kotlin 앱의 Android SpeechRecognizer 구현과 RecognitionService 조회를 제거했다. 자체 Whisper만 사용하고, 모델 미설치 시 다운로드 안내와 직접 입력을 제공한다. Android TTS 음성 안내는 유지한다.
- 음성 인식 원문과 보정 문장 표시, 안내 시작 버튼을 제거했다. 메뉴 보정 및 주문 해석에 성공한 주문은 주문 확인 내용을 표시하며 새 카메라 화면으로 안내를 시작한다. 직접 입력 주문에도 같은 흐름을 적용한다.
- 주문 요약 문구를 ‘맞나요?’에서 ‘이 주문으로 안내합니다’로 변경했다.
- 메뉴 보정의 애매한 후보는 선택 전 안내하지 않는다. 미등록·품절·잘못된 수량·상충 옵션은 기존 파서로 차단한다. 추천 후보 선택은 주문을 자동 생성하지 않고 편집 가능한 입력란만 채운다.
- 자체 모델 미설치·음성 인식 실패 시 기기 인식으로 전환하지 않는다. 설정 이동·백그라운드 전환으로 취소된 비동기 결과는 기존 세대 식별자로 폐기한다.

## 범위와 한계

주문 확인 패널은 추가했지만 화면 높이·스크롤 배치는 3단계에서 조정한다. 설정/종료/재인식 버튼 구성 및 복귀 정책은 4단계에서 변경한다.

수량 미언급 시 1개로 처리하는 기존 정책과 매장/포장 미언급 시 해당 키오스크 단계에서 멈추는 정책은 유지한다. 모델 가중치·디코딩 성능은 변경하지 않았다. 실제 한국어 마이크 입력과 전체 키오스크 주문은 이번 검사로 검증하지 않는다.

## 검증

- Kotlin 단위 테스트 74개 통과, 실패 0개.
- 디버그 앱·Android 테스트 APK 빌드 성공.
- Android 15 에뮬레이터 NativeAppTest 7개 통과: 정상 인식 텍스트의 자동 안내·인식 원문 비표시·잘못된 수량 차단, 직접 입력 자동 안내, 추천 후 재입력, 카메라 중지/재개, 설정 잠금/종료, 상세 OCR 취소·화면 이동. 실제 마이크 추론 대신 인식 텍스트를 입력해 주문 이후 흐름을 검증했다.
