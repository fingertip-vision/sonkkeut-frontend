# develop_ux · 4단계: 환경 설정·종료·재인식 버튼

2단계 커밋 60f6a2d 위의 3·4단계 미커밋 변경이다. 기존 공개 APK에는 아직 반영되지 않았다.

## 적용

- 시작 화면과 주문 안내 화면의 설정 버튼은 같은 환경 설정으로 직접 이동한다. 환경 설정에는 화면·카메라·음성 항목을 표시하고, 글자/색상/목표 강조/넓은 카메라/음성/진동/속도 설정 및 저장은 유지한다.
- 메인 메뉴바는 설정 → 종료 순서다. 종료 버튼은 노란색이며 주문 세션을 종료하고 시작 상태로 돌아온다. 최초 시작 화면에는 종료 버튼이 없다.
- 안내 계속·안내 중지 버튼을 제거했다. 안내 중에는 ‘음성 재인식’ 버튼을 비활성 상태로 표시한다. 재인식·녹음·주문 초기화 등의 동작을 연결하지 않았다. 기존 재안내 버튼은 유지한다.
- 이전 메뉴 화면과 서버/매장·화면 읽기·상세 OCR·수동 인식 복구·통계 동의·최근 자막 등의 화면 진입점을 제거했다. AI 추론·상세 OCR·서버 자동 연결·기존 저장 설정·메뉴 추천의 내부 코드는 유지한다. 서버 주소/매장 코드를 바꾸는 사용자 화면은 이번 UX에서 제공하지 않는다.
- 자체 음성 모델 다운로드/취소는 메인의 주문 입력 화면에서 유지한다.

## 설정 복귀 정책

안내가 실행 중일 때 설정을 열면 카메라·안내·녹음을 멈추고 이전 비동기 결과를 폐기한다. 같은 앱 안에서 설정을 닫으면 기존 주문을 유지한 채 이전 목표를 폐기하고 새 화면을 요청하여 안내를 자동 재개한다. 시작 전/이미 중지된 상태/결제 도착 상태에서는 설정을 닫아도 자동 시작하지 않는다.

설정 중 백그라운드로 나가면 자동 재개 예약을 취소한다. 메인으로 돌아온 뒤 카메라 다시 시작을 눌러 재개할 수 있다. 종료는 복귀 예약과 주문을 초기화한다. 기존 미확인 담기와 중복 담기 보호는 유지한다.

## 검증

- Kotlin 단위 테스트 74개 통과.
- Android 15 앱 검사 8개·배치 검사 2개(총 10개) 통과.
- 설정 화면의 일치, 안내 중 설정 진입 시 중지/복귀 자동 재개, 시작 전 복귀 시 자동 시작 없음, 백그라운드 후 복귀 시 중지 유지, 서버 설정 잠금, 메인 종료 동작, 재인식 비활성 버튼을 확인했다.
- 실제 메인 버튼 컴포넌트를 쓰는 360×640dp 배치에서 글자 배율 1.0/2.6의 주문 전체 페이지 표시와 설정/종료 순서를 확인했다. 버튼 컴포넌트 분리 후 관련 검사 3개를 재실행하여 통과했다.
- 큰 글자의 진행 화면에서는 상단 앱 이름을 생략하고 현재 안내를 한 줄로 표시해 주문 확인 공간을 확보한다. 큰 글자는 남은 세로 공간의 카메라 8%·주문 확인 92%를 사용하고, 버튼 안쪽 여백을 줄여 과도한 줄바꿈을 방지한다. 주문 내용은 글자 크기를 유지하며 페이지로 확인한다.
- 주문 확인 상태로 전환하면 입력 키보드를 닫는다. 백그라운드 복귀 등 중지 상태에는 확인 패널을 숨겨 카메라 다시 시작 버튼의 공간을 확보한다.
- 시스템 영역/앱 여백 포함 큰 글자에서 재인식 버튼이 3줄로 늘어나 확인 영역을 차지하는 문제를 발견했고, 버튼 여백과 카메라/상단 배치를 조정한 뒤 관련 검사 3개를 재실행하여 모두 통과했다.
- 최종 소스에서 정상 주문 후 설정 → 백그라운드 → 메인 복귀 시 중지 유지/재인식 비활성/카메라 다시 시작 버튼 표시 검사 1개를 재실행해 통과했다.
