# AI 모듈 동기화 · Kotlin 앱 0.2.1

작업 브랜치는 `develop_kotlin_ui_integration`이며 AI의 같은 개발 브랜치 `codex/unified-ai-20261003`를 `d1685e9`에서 `80d3dfcdaec24144334e1236319237bf44651154`로 동기화했다. 프론트 다른 브랜치를 병합하지 않았다. 모델 가중치 5개는 기존 통합 APK와 동일하다.

## 새 기능 사용 방법

**메뉴 추천:** 등록된 메뉴를 찾지 못하거나 이해하지 못한 주문에서, 비슷한 철자·제한된 음식 분류를 사용해 등록된 후보를 최대 3개 표시한다. 품절 메뉴는 제외한다. 후보를 누르면 주문 입력란에 메뉴 이름만 들어간다. 수량·온도·옵션·매장/포장을 다시 입력하고 `입력한 주문 확인` → `네, 이 주문으로 안내 시작`을 눌러야 안내한다. 원래 주문의 수량·옵션을 대체 메뉴에 몰래 적용하지 않는다. 임의의 음식·재료·알레르기를 이해하는 LLM 기능은 아니다.

**가까이서 상세 글자 읽기:** `메뉴·설정` → `가까이서 상세 글자 읽기`를 누르면 기존 안내를 멈춘다. 카메라에 읽을 글자를 가까이 비춘 뒤 `상세 읽기 시작`을 누른다. 겹치는 6개 영역에서 글자를 읽어 확실한 문장만 표시한다. `읽은 내용 음성 안내`로 들을 수 있다. 읽는 동안 취소할 수 있으며, 닫기·설정 이동·앱 백그라운드 전환·종료 뒤 도착한 결과는 폐기한다. 상세 OCR의 부분 영상 좌표로 손끝 안내 목표를 만들지 않는다. 주문 안내를 다시 하려면 상세 읽기를 닫고 `안내 계속`을 눌러 전체 화면을 새로 확인한다.

**손끝 상태:** 새 `tip_conf`·`tip_pointing` 값을 시각 안내에 연결했다. 손끝 신뢰도가 낮거나 검지가 펴지지 않으면 재확인 문구를 표시한다. 자동 스크롤·스와이프 실행을 추가한 것은 아니다.
