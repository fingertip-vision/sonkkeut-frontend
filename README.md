# 손끝길 · Kotlin Android 앱 0.3.1

**현재 개발 진행 중입니다.** 시각장애인·저시력 사용자가 키오스크 화면을 카메라로 비추고, 주문할 메뉴를 말하거나 입력하면 화면 인식과 손끝 이동 안내로 주문을 돕는 앱입니다. 결제는 키오스크에서 직접 진행합니다. 실제 키오스크에서 혼자 주문을 끝낼 수 있는지는 아직 현장 검증이 필요합니다.

## 이번 UI/UX 개선 · 0.3.1

주문 팝업을 닫아도 메뉴·수량·온도·크기·매장/포장 내용을 확인할 수 있습니다. 시작 화면은 스크롤 없이 화면 높이와 글자 크기에 맞춰 로고·장식 문구를 조절합니다. 설정·시작·재안내 조작을 우선 배치합니다.

음성 모델 준비, **음성 인식 중**, **음성 분석 중**, 주문 확인을 구분합니다. 마이크가 실제로 열렸을 때 인식 중으로 표시하고, 자동 또는 수동 녹음 종료 후 마이크를 해제하면 분석 중으로 바꿉니다. 기존 1.2초 무음 종료·6초 무발화 대기·30초 상한과 Whisper 모델·인식 설정은 유지합니다. 녹음된 음성을 보존하며, Whisper 변환 동안 카메라 미리보기는 유지하고 영상 분석만 잠시 쉬어 CPU 경쟁을 줄입니다. 실제 휴대폰에서 인식 속도가 얼마나 개선됐는지는 별도 측정이 필요합니다.

대체·추천 및 모호한 음성 메뉴 후보는 현재 카메라가 읽은 화면의 메뉴로 제한합니다. 화면 이탈·카메라 중지·오래된 결과는 후보에서 제외하고 선택 직전에도 확인합니다. 후보 선택은 메뉴 이름만 입력란에 넣으며 수량·옵션을 다시 확인해야 합니다.

**글자 인식 영역 확인 · 5초**로 읽힌 메뉴·버튼 영역을 잠시 표시합니다. 실선은 높은 읽기 신뢰도, 점선은 확인 필요이며 현재 화면의 기울기에 맞춰 투영합니다. 개별 글자 획이나 문장별 경계가 아닙니다. 기존 결과를 재사용하므로 표시 버튼이 OCR을 추가 호출하지 않으며, 손끝 안내는 유지합니다.

0.3.1 APK는 빌드됐으며, 아래 공개 다운로드는 이전 배포인 0.3.0입니다.

## 현재 주문 화면

| 항목 | 현재 동작 |
|---|---|
| 주문 후 안내 | 정상 주문이면 주문 팝업을 표시하고 주문 음성 안내 후 자동 안내를 시작합니다. 음성 출력이 꺼져 있거나 준비되지 않았으면 화면 표시 후 시작합니다. |
| 음성 인식 | 모델 준비·음성 인식·음성 분석·주문 확인을 구분하며 자체 Whisper와 한국어 Android TTS를 사용합니다. |
| 주문 확인 화면 | 카메라 크기를 유지하고 아래쪽에 팝업으로 표시합니다. 짧은 주문은 페이지 버튼이 없고, 긴 주문만 이전·다음으로 확인합니다. 닫은 뒤 주문 보기로 다시 열 수 있습니다. |
| 손끝 안내 | 손끝 미검출·이동·누르기·결과 확인을 구분합니다. 오래되거나 현재 대상과 맞지 않는 인식 결과는 방향·목표 표시에서 제외합니다. |
| 설정·종료 | 메인 상단에 설정·종료를 표시합니다. 첫 시작 화면에는 종료가 없습니다. 설정에는 화면·카메라·음성 항목을 제공합니다. |
| 음성 재인식 | **기능은 미구현이며 버튼도 비활성**입니다. 재안내는 사용할 수 있지만 녹음·처리·안내 중지 중에는 비활성입니다. |
| 설정·앱 복귀 | 안내 중 설정에서 돌아오면 새 화면을 확인해 재개합니다. 다른 앱으로 갔다가 돌아오면 중지 상태이며 ‘카메라 다시 시작’을 누릅니다. |

메뉴가 불확실하거나 품절·미등록·수량·옵션 오류가 있으면 바로 안내하지 않습니다. 추천 후보를 고른 경우에도 수량·옵션을 다시 입력해야 합니다. 화면 인식과 누름 결과 확인, 매장별 메뉴 보정·캐시, 서버 자동 연결은 유지합니다.

## 사용 순서

1. 앱을 열고 준비가 끝나면 **손끝길 시작**을 누릅니다.
2. 카메라로 키오스크의 전체 화면을 비춥니다. 화면과 메뉴가 준비되면 주문 입력을 요청합니다.
3. 자체 음성 모델을 준비한 뒤 말하거나 **직접 입력 주문**을 사용합니다. 예: ‘따뜻한 아메리카노 두 잔하고 카페라떼 한 잔 포장해 주세요.’
4. 정상적으로 해석되면 주문 확인 내용을 표시하면서 안내를 시작합니다. 오류나 후보 선택 요청이 있으면 내용을 수정합니다.
5. 음성·화면 안내를 따라 손끝을 움직이고 키오스크 버튼을 직접 누릅니다. 앱은 화면 변화와 담기 결과를 확인합니다.
6. 안내를 끝내려면 상단의 **종료**를 누릅니다. 결제는 키오스크에서 직접 진행합니다.

현재 환경 설정에는 서버·매장 변경과 화면 전체/상세 글자 읽기 진입점이 없습니다. 기본 서버와 매장 메뉴에 자동 연결하며, 주소가 바뀌면 앱의 기본 연결 설정을 갱신해야 합니다.

## 개발 환경

**Kotlin + Jetpack Compose + CameraX**를 사용합니다. Android Studio에서 저장소의 **루트 폴더**를 여세요. 루트 `app/`가 현재 Android 앱이며 `android/`와 기존 TypeScript 파일은 이전 구현 참고 자료입니다.

두 저장소를 같은 부모 폴더에 둡니다.

```text
workspace/
  sonkkeut-frontend/  ← Android Studio에서 Open
  sonkkeut-ai/
```

AI 모듈 기준 커밋은 `d9938b2f3e999b093942c4a882264a3fbc2ca8b8`입니다. JDK 17, Android SDK 35와 AI 모듈 빌드에 필요한 NDK·CMake를 준비하고 `JAVA_HOME`·`ANDROID_HOME` 또는 Android Studio의 SDK 경로를 지정하세요.

```powershell
.\gradlew.bat :app:assembleRelease :app:testDebugUnitTest
# 에뮬레이터 또는 기기를 연결한 뒤
.\gradlew.bat :app:connectedDebugAndroidTest
```

빌드 결과는 `app/build/outputs/apk/release/app-release.apk`입니다. APK 설치만 할 때는 개발 도구와 AI 소스 저장소가 필요하지 않습니다. [Android Studio 실행·모듈 설명](docs/native-kotlin.md)을 참고하세요.
